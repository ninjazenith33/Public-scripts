# Perl Playground

A collection of random Perl scripts I've written while learning Perl.

This repository is part learning project, part experiment, and part archive of useful (and sometimes not-so-useful) ideas. You'll find a mix of automation tools, system utilities, troubleshooting scripts, coding exercises, and whatever else I happen to be working on at the time.

## About

I'm learning Perl and using it to build small projects, explore concepts, and solve problems that catch my interest.

Not every script here is polished. Some are complete tools, some are experiments, and some may simply be proof-of-concepts that helped me learn something new.

## What You Might Find Here

- Command-line utilities
- Linux administration scripts
- File and text processing tools
- Automation projects
- Monitoring and diagnostics tools
- Learning exercises
- Experimental code
- Random ideas that turned into scripts

## Why This Repository Exists

- To document my Perl learning journey
- To share useful scripts with others
- To practice programming concepts
- To have a place for projects that don't fit anywhere else
- Because sometimes the best way to learn is to build something

Some scripts may be incomplete, experimental, or written primarily for learning purposes. Always review code before running it, especially on systems that contain important data.
